1. Basics

CSS is used to style and design documents. Most often it is used to design HTML documents.

1.1 Adding CSS

CSS can be included in HTML in three ways:

  1. Inline CSS:
    Inserted directly in the HTML tag.
    Example:
    <h1 style="color: red">Heading</h1>
  2. Internal CSS:
    Embedded in the <head> using the tag <style>
    Example:
    <head>
    <style>    h1 {
    color: red;
    background-color: yellow
    }
    </style>
    </head>
  3. External CSS:
    Refers to a separate file by linking it, typically within the <head>. Best practice for clean code.
    Example:
    <link rel="stylesheet" href="css/style.css">

1.2 CSS Cascade

The cascade in CSS is the algorithm that defines how different CSS sources are managed and prioritized.
